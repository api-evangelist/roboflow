Correct, fine-tuning SAM3 is only for Enterprise users at this time. Although that’s such a massive model, if you really needed to fine tune and use a model you might prefer something like RF-DETR. You can use SAM3 as-is if you want to get a jump start on annotating to fine-tune a different segmentation model.
